# Tom Lee - This crypto cycle looks different because on-chain activity is still accelerating

## Position
Tom Lee argues this crypto cycle differs from prior ones because on-chain activity is still accelerating instead of turning down.

## Evidence Cited
- Lee says active addresses, daily activity, and total value locked are still rising.
- He contrasts that with prior cycles where on-chain activity would usually turn down.
- He uses those differences to argue that this cycle may not follow the old four-year template.

## Logic Chain
1. Lee points to current on-chain measures that remain strong.
2. He contrasts those data points with prior cycle behavior.
3. Therefore he concludes this cycle looks materially different.
