# Antonio Gracias - Voting systems should be run to a zero-defect standard because an illegal vote cancels out a lawful one

## Position
Antonio Gracias argues that election systems should aim for zero defects because even a single illegal vote dilutes a lawful one.

## Evidence Cited
- Transcript says every illegal vote nullifies the vote of an American citizen.
- He says Americans deserve a zero-defect system for voting.
- He compares that standard to quality control in medical-device production.

## Logic Chain
1. Voting is a core constitutional process.
2. Error tolerance that might be acceptable elsewhere is not appropriate for vote integrity.
3. So election administration should target extremely low or zero known defects.
