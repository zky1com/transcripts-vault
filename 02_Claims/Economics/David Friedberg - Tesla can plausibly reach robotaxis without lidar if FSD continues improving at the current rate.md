# David Friedberg - Tesla can plausibly reach robotaxis without lidar if FSD continues improving at the current rate

## Position
David Friedberg argues that Tesla can plausibly reach robotaxis without lidar if FSD continues improving at the current rate.

## Evidence Cited
- He says recent FSD updates have sharply reduced disengagements in everyday driving.
- He treats the current supervised experience as evidence that the core system is already highly functional.
- He explicitly says he believes Tesla can do real robotaxis in roughly two years despite the camera-only approach.

## Logic Chain
1. If a vision-only system is already delivering near-robotic driving in supervised use, continued incremental improvement can close the remaining commercial gap.
2. Friedberg says Tesla is on that path now.
3. That supports his claim that robotaxis without lidar are plausible if improvement continues.
