## Summary

This demo presents Prism as an AI-native workspace for scientific writing and collaboration, with Alex showing how it pulls ChatGPT directly into a LaTeX-style research environment. The core pitch is that scientists should not have to bounce between a paper draft and separate chat windows for writing help, diagram generation, literature review, or mathematical checking. By keeping full project context inside the editor and allowing multiple parallel chats, Prism aims to remove research drudgery and give scientists more time for actual discovery.

## Key Insights

- The strongest value proposition is workflow integration rather than raw model capability alone.
- Prism treats scientific writing as a context-rich environment where AI should work inside the editor, not beside it.
- Parallel chat windows make literature search, writing revision, and equation checking feel like simultaneous collaborators.
- Technical chores like diagram production and citation hunting are framed as high-friction tasks that AI can absorb.
- The demo positions AI as a force multiplier for scientific focus by removing repetitive formatting and lookup work.
